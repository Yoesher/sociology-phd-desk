# 同类研究工作站检索与修正方案

检索日期：2026-10-04。基线：应用 0.4.1 / main `656b99ac708760b4aae684be8c4b19a95c7608a2`。用户授权本轮检索、实施、测试与发布。此方案的实施目标为 **0.5.0 研究导航**；方案不是上线证据，实际发布状态见 PROJECT_STATE、对应 PR 与正式 Release。

## 检索方法与证据边界

围绕学术知识笔记、文献管理、定性编码、田野地图、结构化记录及研究项目组织，跨产品检索官方帮助、官方文档及项目自身源码。记录可追溯页面、实际读到的能力、适合本项目的工作流与不采用的依赖。检索不是全网穷尽，也没有实装或付费体验全部产品；官方功能说明不能替代本项目的验收。没有复制产品源码、商标、截图、模板资产或用户资料。

本项目的长期定位仍是中文优先、本地优先、无需账户的社会学研究协调层。保留现有九个研究域、离线 PWA、完整工作台备份、加密与匿名田野边界。专业引用、全文编码、GIS、统计运算与论文排版继续交给相应工具。

## 当前缺口与修正原则

1. **记录分散。** 当前各模块可以筛选，却缺少统一搜索入口。研究者不知道某段判断放在文献笔记、理论 memo 还是研究日志时，要逐个打开模块。修正为直接搜索当前已解锁工作台的研究文本；默认遵循项目范围，也可明确扩展到所有项目。
2. **已有关系难回看。** question↔claim、理论 memo、田野点/地图/访问/访谈、数据集/分析、论文/投稿/审稿已有稳定关系。修正为统一只读详情及双向关联列表，可连续查看关联记录。证据的 claim/source/manuscriptLocation 仍为自由文本，不能据名称猜成已建立链接。
3. **项目状态与实际积累脱节。** 手工阶段值不解释正在积累什么。修正为实际任务、问题、主张、资料、田野点、分析与论文计数，过期/七天任务和未关联问题提醒。任务完成数仅表示任务；不计算研究质量、成熟度、饱和度或“项目完成率”。
4. **地图需要接入研究对象。** 首版的离线自有草图已有标注；本轮使地图和田野点、访问、访谈在导航中互相可查。仍使用图内百分比，不推断经纬度，不改变图片或导入在线底图。
5. **容量不能只加数字。** 保留 PDF 10/20 MiB、图像 2/4 MiB、普通 JSON 32 MiB 与现有认证加密边界；下一阶段先设计独立附件存储、清单一致性、分块认证备份和恢复，才能支持大文献库。
6. **论文证据链需要真实模型。** 后续新增 Evidence↔Claim↔Manuscript 稳定多对多关联必须独立 schema/migration/删除保护和兼容验证，不能把本轮既有关联浏览写成完整证据链已实现。
7. **操作一致性。** 后续统一仍缺少编辑/删除的记录类型、失败草稿保留与受保护关系解除；本轮详情为只读，通过明确“前往原模块”回到既有操作，避免新增另一套写入表单。

## 本轮 0.5.0 实施规格

### 统一研究导航

- 桌面与手机均有研究导航入口；非输入状态可用 Ctrl/Cmd+K。已有编辑表单或对话框打开时不抢快捷键，关闭恢复焦点。
- 两个面板：检索记录、项目概览。使用现有 Modal 和外观/减少动态效果体系；不添加第三层导航。
- 17 种可见研究实体：项目、问题、主张、理论 memo、任务、文献、田野点、地图、访谈、访问、数据集、分析运行、证据、研究日志、论文、投稿、审稿意见。关系行与 Zotero 来源身份是辅助数据，不混作独立研究记录。
- 搜索标题及明确允许的研究文本/日期/书目字段；大小写无关、Unicode NFC 归一化，空白分词全部匹配，标题优先，再按修改时间和稳定键排序。不执行用户正则。
- 查询只保留于窗口内存，不写 URL、local/session storage、研究备份、遥测或网络。PDF/图像字节、附件全文、专用文件系统路径字段与其他锁定工作台不索引。
- 结果按类型/项目筛选，显示实际总数，每页最多 40 条，全部结果可翻页，不用截断冒充完整列表。
- 详情按明确字段标签显示用户原文，稳定 ID 关联可继续打开；长文字换行。原模块链接只导航模块，不宣称直接打开编辑器或自动定位记录。

### 项目概览

- 默认当前项目；未选项目时查看所有项目。
- 实际已完成/全部任务数，未完成且非延期任务的过期数和未来七天数；日期沿用前台午夜/焦点刷新。
- draft/active 问题数与其中无显式 ClaimQuestionLink 的问题数；提醒是工作安排线索，不是学术评价。
- 文献、理论 memo、田野点、已标注唯一田野点、访谈、数据集、分析运行、证据、论文及待处理审稿意见计数。
- 可点击计数进入当前导航的对应项目/类型记录列表，不改项目选中状态、不重写研究数据。

### 数据与隐私

数据契约继续 v7，container/vault/registry v1。全部能力为当前解锁快照上的只读投影，查询索引不持久化；锁定/工作台切换由既有访问门控制卸载全部研究 UI。备份仍完整保留所有项目、19 个集合、PDF/图像/标注，不携带导航查询。新增中英文消息，同步 package/lock/citation/releaseMetadata 与帮助说明。不引入新依赖、远程字体、在线地图、账户或默认同步。

## 验收与发布门禁

1. 单元测试：17 实体、中文/英文多词/Unicode、排序与分页范围、只读与附件排除、同项目关系双向/无文本推断、真实日期/计数语义。
2. 组件测试：项目/类型筛选、空结果、详情/关联、分页、关闭/焦点、双语概览与只读边界。
3. 执行原始命令：npm ci、audit:release、lint、typecheck、npm test、test:zotero、build、test:e2e。现有桌面和手机测试全部保留，新增导航场景两视口都跑。
4. 每次 Zotero 构建核对并恢复既有 updates.json 正式资产哈希；仅提交源代码、文档及合成截图，不提交 dist/node_modules/测试输出/机器适配器。
5. 专用分支提交/推送/PR；核对最终 head 的 push/PR CI 和 CodeQL，独立 P0/P1 审查后用 expected head 合并。
6. 合并后核对最终 main 的 CI/CodeQL/Pages；公开页面、manifest、SW、静态资源、版本及完整构建 SHA。独立合成桌面/触屏烟测、控制台、布局和真实旧版本更新保留。
7. 正式 Release 只在最终 main 验收后建立新标签；旧标签及 Zotero 插件资产不移动。UTF-8 Release 文件先校验，上传后读取 API 核对。新文档提交若产生新 SHA，必须重新完成它自身的远端与公开验收。

## 完整后续路线图及进入条件

| 次序 | 下一项 | 必须先解决 | 可验收结果 |
| --- | --- | --- | --- |
| 1 | 大附件架构 | 所有权、配额、事务一致性、迁移、孤儿清理；普通/加密清单与分块认证格式 | 大 PDF 不重复复制进每次快照，完整备份逐块校验，部分失败不破坏现有工作台 |
| 2 | 完整证据链 | 显式 Evidence↔Claim、Claim↔Manuscript 模型、v8 迁移、同项目与删除保护 | 研究者明确建链、反证/局限可查，旧自由文本原样保留、不猜链接 |
| 3 | 田野分析支持 | 匿名抽样类别、研究者定义编码、memo 与资料定位、伦理与范围 | 基于真实记录的采样矩阵与编码反查；不自动判断饱和度或推断受访者位置 |
| 4 | 离线地图可读性 | 缩放/平移/选点键盘模型、图片尺寸预算、触屏可用性 | 标记与视图缩放独立，保存/恢复百分比一致，不增加在线请求 |
| 5 | 可复现分析比较 | 样本/变量/模型/输出版本字段及真实关系 | 运行差异并列、失败与缺失保留，不替代 Stata/R/Python 执行与证据 |
| 6 | 写作修回流程 | 稳定稿件位置、审稿意见/行动/证据关联与局部导出 | 逐条回复矩阵和可编辑交接，不生成未经来源支持的引文或论证 |
| 7 | 保存视图与研究模板 | 明确用户创建流程、类型化配置与 backup 边界 | 用户主动选方法框架或保存筛选；默认不注入假文献、访谈、结论 |
| 8 | 用户可用性验证 | 合成任务、键盘/屏幕阅读器、实机手机/安装式 PWA | 记录真实任务成功率与问题，不把维护者自测当外部采用 |

每项独立定范围、实现、迁移及发布验收。不把未实施方案标为已完成，不为吸收竞品功能而破坏本地数据边界。
