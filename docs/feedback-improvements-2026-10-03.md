# 社会学工作站使用反馈优化说明

这份说明对应 2026 年 10 月 3 日已更新到现有 GitHub Pages 的 **0.3.1 应用**。发布 PR [#55](https://github.com/Yoesher/sociology-phd-desk/pull/55) 的功能合并提交为 `7f50ecd209b1a9deac3b9bc38653f798020a5817`；精确检查与部署记录见 [PROJECT_STATE.md](../PROJECT_STATE.md)。正式 GitHub Release/tag 仍保留 v0.3.0，本次没有创建或移动标签。

## 找回列表中被筛选的文献

文献页新增“显示全部文献”，同时显示“当前显示多少篇、已保存共多少篇”。点击后会清除搜索词、项目筛选、阅读状态、优先级以及地址中的文献视图筛选。进入某个项目空间时，这里的“全部”指该项目的全部文献；需要查看其他项目，请先把页面上方“项目空间”改成“全部项目”。

手动添加或确认 Zotero 导入成功后，列表会切换到当前范围的全部文献并显示保存提示。每条记录都有“查看／编辑”入口，可以重新查看和补充作者、出版信息、阅读理由、笔记及附件。保存失败时，表单中的内容会保留。

先前只看到一篇的情况，可能与同时启用搜索、项目、“已读”、“关键”等筛选有关。这个入口可以检查被筛选的记录；目前没有检查你的实际浏览器数据库，因此还无法确定先前的文献是否发生数据丢失，也不能声称已经恢复了那些记录。

## 使用本地 PDF，无需 Zotero

1. 在文献页点击“添加 PDF”，或者在手动添加文献的表单中选择“本地 PDF”。
2. 选择文件后，表单会显示选中的文件名。题名可以从文件名开始填写；作者、年份、期刊等信息需要手动核对，并填写阅读理由。
3. 点击保存，等待保存成功提示。回到列表可以通过“下载 PDF”重新取出附件，也可以通过“查看／编辑”补充记录。

每个 PDF 最大为 **5 MiB**，一个工作区内所有 PDF 合计最大为 **12 MiB**。超出限额或文件格式不符合要求时，会显示原因并保留输入。较大的论文和批量文献可以继续放在原有文件夹中，工作站只登记关键信息。

PDF 与文献记录一起保存在当前浏览器的工作区中，并随整个工作区的便携或加密备份导出。普通工作区和普通 JSON 备份包含明文文件内容；使用加密工作区或加密备份时，附件随工作区内容一起加密。原有文件夹里的文件仍然需要按你的习惯保留和备份。

“导入 Zotero 交接文件”是单独的入口，用于 `.spdzotero` 或 `.sociology-zotero.json` 元数据文件。它不会导入 Zotero PDF 附件。本轮也没有新增自动识别论文题名、作者或全文的功能。

## 在一个项目内开展工作

页面上方新增“项目空间”选择器，也可以从项目详情中点击“进入项目”。进入后，各研究模块中与项目关联的记录只显示当前项目的内容，新增记录自动关联这个项目，减少反复选择项目的操作。侧栏提醒也按照当前项目统计；“工作台共同的今日目标”仍由整个工作区共用，页面会标明这一点。

切换到“全部项目”可以重新查看跨项目内容。切换项目只改变当前显示范围；其他项目的记录继续保存在原工作区，工作区备份仍包含所有项目。项目空间和普通／加密工作区是不同层级，项目之间没有新增独立数据库或隐私隔离。

在某个项目空间中导入 Zotero 文件时，如果同一来源已关联其他项目，会跳过这条来源，避免误改另一个项目。需要处理跨项目关联或更新时，先返回“全部项目”。

## 重新查看和修改任务期限

任务列表新增实际截止日期，并显示“今天到期”“还剩几天”或“已逾期几天”；未设置日期的任务会显示“未设截止日期”。页面还汇总今天到期、未来七天到期和已逾期的未完成任务，“未来 7 天”筛选包含今天至第六天。

点击任务旁的“查看／编辑任务”，可以再次查看和修改截止日期、工作类型、优先级及备注。编辑会保留原有完成状态，日期也可以清空。新建或编辑保存成功后，任务视图会切换到全部任务，便于立即核对。

这次增加的是打开工作站时可见的期限提示。关闭网页后不会发送系统通知、邮件或其他主动提醒。

## 数据与版本

0.3.1 应用使用工作区数据格式 v6，旧版工作区会经过明确升级，保留已有文献、项目记录及 Zotero 出处。新格式备份需要支持 v6 的应用；旧的 v5 应用不能直接读取新格式备份。

本轮没有建立账号、云同步或自动上传，也没有重置、覆盖或检查你的真实研究工作区。维护者只用独立浏览器上下文中的合成数据验证。上一会话创建远端分支被审批策略拒绝的记录保留在项目状态中；本会话真实进展与线上验收按实际提交 SHA 单独记录。
