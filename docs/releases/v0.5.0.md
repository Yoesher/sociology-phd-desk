# 0.5.0 研究导航 / Research navigator

日期：2026-10-04。此文件描述本轮实现与使用方式；发布状态和最终构建身份以项目状态、对应 PR 及[正式发行版](https://github.com/Yoesher/sociology-phd-desk/releases/latest)的实际记录为准。

## 从同类工具到本地研究工作流

本轮在 0.4.1 基础上，检索 20 个代表工具的官方资料，形成[完整修正方案](../research-workstation-review-2026-10-04.md)、[知识工具比较](../research-workstation-notes-comparison.md)和[田野/文献工具比较](../research-workstation-field-comparison.md)。方案不声称穷尽全网或实装全部产品。借鉴的是跨对象检索、明确关系、派生视图和完整备份的工作方法；没有复制其品牌、源码或研究资料。

桌面顶栏和手机页头的放大镜打开“研究导航”，也可在非输入状态用 Ctrl/Cmd+K。编辑器或其他弹窗已打开时不会抢占快捷键。

### 找回跨模块记录

“检索记录”覆盖当前已解锁工作台的 17 类实体：项目、问题、主张、理论备忘、任务、文献、田野点、地图、访谈、田野访问、数据集、分析运行、证据、研究日志、论文、投稿和审稿意见。

默认遵循当前项目；勾选“检索所有项目”可明确扩大范围，也可选择项目与记录类型。标题、笔记、书目与研究描述的词以空格分开，全部匹配，英文大小写无关；支持 Unicode NFC 文本。不执行正则、模糊语义或 AI 检索，系统枚举保持原持久化值。空检索按最近修改浏览；每页 40 条，显示总数，所有匹配结果可翻页。查询最多 200 字符。

点击记录查看详情；用户文字不因界面语言切换而改写。导航只读，不添加另一套编辑表单。“前往原模块”进入既有模块与原项目显示范围，用该模块筛选和表单操作；它不是直接打开特定记录编辑器。

### 看清已经登记的关联

详情列出真实稳定 ID 关系：问题↔主张、理论备忘↔问题/主张/文献、地图↔田野点↔访问/访谈、数据集↔分析运行、论文↔投稿↔审稿意见，以及项目归属。点击可以连续浏览。

仅显示同项目且对象实际存在的关联，每页40条并可翻页查看全部关联。不会从同名或相似文字推断关系。证据的 claim/source/manuscriptLocation 仍是自由文字，本轮不声称完整 Evidence↔Claim↔Manuscript 显式追踪已完成。地图关系仍是本地自有粗粒度草图的图内标注，不是经纬度或在线地图。

### 用实际记录安排下一步

“项目概览”显示任务已完成/全部数、非完成/非延期任务的逾期与今天起七个日历日到期数、draft/active 问题及未关联主张的问题数、资料/分析/写作对象计数和唯一已标注田野点覆盖。计数可以进入相应项目和类型的完整记录列表；期限等细分计数打开的是该类型全部记录，文案会说明这一点。

这些计数是工作安排线索。任务完成数不代表项目完成率；未关联问题不代表研究不合格；点位数量不判断抽样质量或理论饱和。

## 保持的数据边界

- 导航查询、结果与索引只存在当前窗口内存，不写浏览器历史/URL、localStorage/sessionStorage、研究备份或网络。关闭导航后销毁查询；锁定/切换工作台由既有访问门卸载研究 UI，不检索别的锁定工作台。
- 不索引 PDF 正文、PDF/图像字节、附件文件名、专用 URL/文件系统路径字段；手工笔记原文中的 URL 或路径不被剥离。研究数据仍以原来的完整快照保存、导入和备份，浏览导航不写项目状态或 activeProject。
- portable/standard/authenticated payload 仍为 v7；container/vault/registry v1。无需研究数据库迁移。PDF10/20 MiB、图像2/4 MiB、普通完整 JSON32 MiB、现有加密边界保持不变。
- 中英文、四类外观/字体/字号/动效设置、离线写入、显式 PWA 更新和普通/加密完整备份保留。无新增依赖、账户、云同步、远程字体、地图/GPS服务或后台通知。

## Research navigator in English

Open the magnifier in the desktop topbar or phone header. Ctrl/Cmd+K works outside inputs and existing dialogs. Search the 17 record kinds in the current unlocked workspace, within the selected project or explicitly across all projects. Space-separated literal terms must all match; title matches rank first, followed by last update. Results show actual totals with 40-record pages. Queries are transient and never sent to a service or stored in history/backups.

Read-only details follow existing same-project stable-ID relationships. Free-text evidence does not become an inferred claim/manuscript link. “Go to original module” opens the module in the existing scope, where its own filters/forms remain the editing path. Project overview uses actual work queues and object counts, without a quality score, inferred saturation or project completion percentage.

The v7/v1 format boundaries, attachment budgets, complete backup semantics, local-only map model, encryption and bilingual appearance options are unchanged. PDF/image bytes and dedicated URL/path fields are excluded from search. The broader documented roadmap remains future work, including independent attachment storage and explicit evidence-to-claim-to-manuscript links.

## 更新与实际限制

保存输入并生成、验证独立备份后，更新提示可选择“立即更新”，再在帮助/分发中心核对版本与构建身份。不要清站点数据来更新。字体与设置仍依赖当前设备/浏览器，不随研究备份迁移；关闭网页后本站仍不发系统期限通知。实际手机硬件与安装式 PWA 手工验收的状态必须按本轮证据记录，触屏视口不能冒充实机验收。
