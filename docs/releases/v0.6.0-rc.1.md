# 0.6.0-rc.1：定性分析与证据追溯候选

应用候选为 0.6.0-rc.1，发行日期为 2026-10-09；portable workspace、标准数据库和加密载荷为 v9；加密 container、vault database、registry database 仍为 v1。没有新增依赖。此说明在合并前准备，实际发布状态、最终提交、远程测试及部署身份由 [PR #64](https://github.com/Yoesher/sociology-phd-desk/pull/64) 与[候选发行版](https://github.com/Yoesher/sociology-phd-desk/releases/tag/v0.6.0-rc.1)记录；源说明不会提前宣称部署通过。

田野与访谈增加“定性分析”工作流；证据台账增加“证据追溯”。初始/主题编码可跨访谈复用，定义修订保留旧赋码，合并/拆分形成新对象并要求人工重编；匿名案例、抽样维度、比较快照与反例可回看。外部转录和 NVivo/MAXQDA/ATLAS.ti 只登记匿名引用令牌或明确的 HTTPS 引用；资料片段保存行范围、页段、时间范围或外部锚点，不存全文或录音。

分析备忘录是已有 TheoryMemo 的分析属性与历史版本。形成 Claim 的解释链与支持/反驳 Claim 的 EvidenceItem 关系分别登记，避免把理论判断当作经验资料。稳定论文锚点记录文档版本、章节路径、段落标签/书签；实际 EvidenceUsage 固定证据—主张关系与主张—论文位置关系，重定位不会改写过去使用。

v7 的全部19集合与附件保留：v7→v8 仅机械建立现有 Claim/Evidence r1快照，不从自由文本推断关系；v8→v9 增加空定性集合。当前完整工作台共44集合，普通和真实认证加密备份均包含所有项目及历史。旧 0.5.0 无法读取 v9 备份，升级前保留并验证原 v7 备份；不会改写已导出的旧文件。

当前/历史引用均保护删除，不级联擦除。归档资料仍可明确撤回；撤回退休活跃支持与实际论文使用，保留历史并在比较/来源回看显示当前失效状态。删除本地数据库不等于安全擦除，伦理要求的身份清理不由本候选自动实现。

每集合最多25,000条记录，总数最多100,000；每次比较最多1,000案例/编码选择及10,000单元格。普通32 MiB、既有加密64 MiB密文和附件限额保留；超限预览/迁移失败不会截断或部分提交。研究过程元数据也可能敏感，请继续使用匿名 ID。

没有全文编码编辑器、自动转录、AI 自动编码、专业软件项目解析或云同步。研究导航保留原17类型的文本检索；新的定性与版本关系从对应工作流内回看。

验证历史与发布门禁见[候选验收记录](../qualitative-provenance-validation-2026-10-08.md)。发布必须通过确切提交的原 CI/CodeQL、精确 main 的 Pages 和公开构建身份、桌面/触屏普通及加密工作台验收与真实旧 PWA 等待更新保全。最终结果在上述发布记录中逐项登记。触屏视口测试不代表实体手机或操作系统安装版 PWA 已验收。

首版通过表单登记编码演变并显式重新赋码；没有专用的一键合并/拆分编辑器。比较可选择的案例/编码和单元格有上述上限，大规模比较界面的性能仍需后续验证。

English: This is a release candidate for metadata-only qualitative analysis and explicit shared Evidence–Claim–Manuscript provenance, reusing existing research objects. Its verified publication status and exact deployment identity belong in PR #64 and the prerelease. Schema v9 retains v7 data through staged validation; old applications cannot read v9 backups. Keep independently verified original v7 backups before upgrading. No transcription, full-text coding editor, automatic coding, cloud service, or native QDA import is provided. Code lineage is registered through forms; a dedicated one-click merge/split editor and large-comparison UI performance validation remain future work. All examples and tests are synthetic.
