**状态：实现与本地完整验证已通过，远端与公开验收待完成；尚未部署，也未创建 0.4.1 正式 Release/tag。** 当前公开版本与正式 [`v0.4.0`](https://github.com/Yoesher/sociology-phd-desk/releases/tag/v0.4.0) 为 `26d23b4b07fe87d9bca2ce01a37ee11743b32f5f`。后续验证、PR、部署与公开验收使用各自真实提交身份，不能借用 0.4.0 的成功结果。

## 选择适合自己的阅读界面

候选入口为“工作空间与设置 → 外观与动效”，与语言和主题设置一起使用：

| 项目 | 候选选择 |
| --- | --- |
| 界面模板 | 经典研究桌 / Classic research desk、暖纸阅读 / Warm paper、静谧蓝调 / Quiet blue、田野手记 / Field notebook |
| 字体 | 学术混排 / Academic mix、现代黑体 / Modern sans serif、阅读宋体 / Reading serif、系统字体 / System font；仅使用本机字体栈，不下载字体 |
| 阅读字号 | 标准 / Standard、较大 / Large、更大 / Larger |
| 动效 | 轻柔上浮 / Gentle lift、柔和淡入 / Soft fade、轻微平移 / Light slide、关闭动画 / No animation |

默认保留原有外观。模板只调整界面配色与版式，不生成或填充研究项目、记录、引文、结果或访谈内容。系统“减少动态效果”始终优先，选择滑动或轻柔也不能覆盖这一系统偏好。

## 本机偏好与研究数据分开

- 外观与语言、主题共同存入当前浏览器的本机设置，保存时合并已有值，不覆盖其他设置。
- 刷新、切换项目、切换普通/加密工作台、锁定及解锁使用同一份浏览器外观偏好；它不是工作台研究记录，也不需要解密研究数据才能应用。
- 普通 JSON 和 `.sociologydesk` 加密备份不携带这些偏好。恢复到其他浏览器不会自动复制外观；浏览器清除本机设置后需要重新选择。
- 不增加账号、云同步、外部字体请求或遥测。研究数据、引用、附件与研究内容不因外观或语言切换而改写。
- portable/standard/authenticated payload 继续为 **v7**；container/vault/registry 继续为 **v1**，不新增研究数据迁移。PDF、地图、完整备份容量及地图隐私/权利边界保持既有说明。

## English

**Implemented candidate with local release commands passed; remote/public acceptance pending, not deployed and no 0.4.1 formal Release/tag exists.** Use Workspace & Settings → Appearance & motion to select the four templates, four local font stacks, three reading sizes and four motion choices listed above. Defaults keep the previous interface; operating-system reduced motion always takes priority. Templates change interface colors/layout only and insert no research content.

Appearance, language and theme share this browser's local settings and preserve one another when saving. Reload, project/workspace switches and standard/encrypted lock/unlock use the same preference; no research decryption is needed to render it. Ordinary and encrypted research backups exclude these settings, so another browser requires its own selection. No remote font, account, sync or telemetry is added. Research formats stay v7 and container/vault/registry stay v1; existing attachment, backup and map-privacy boundaries remain.
