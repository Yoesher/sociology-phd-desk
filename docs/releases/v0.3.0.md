# Sociology PhD Desk v0.3.0

Sociology PhD Desk v0.3.0 将 Zotero 文献选择、导入预览和更严格的本地数据防护带入同一个不要求账号或云端同步的研究工作站。本版本保持 standard/encrypted workspace 兼容，并继续把研究数据留在用户选择的本地工作台中。

## Zotero 联动

1. 从本 Release 下载 Zotero 插件与 SHA-256 校验文件。
2. 在 Zotero 8 或 Zotero 9 中从文件安装插件。
3. 选中一篇或多篇普通书目条目。
4. 右键选择“发送到 Sociology PhD Desk”。
5. 在 Desk 的导入预览中选择项目、阅读状态和优先级，再确认写入。

Zotero 继续作为书目、PDF、笔记、标注和引用的权威系统。工作站只接收用户明确选中条目的允许书目字段，并对 DOI、ISBN、标题与年份提供保守的重复提示；不会自动合并。

**不读取或导入 PDF、附件、私有笔记或批注。** 插件也不读取全文、附件路径、Zotero 账号或同步状态，不会后台同步或写回 Zotero。

## 主要更新

- 活动一级导航组可以手动折叠和重新展开，本地偏好不会进入研究数据。
- portable workspace 与 standard database 升至 v5；旧 v1 → v2 → v3 → v4 → v5、v4 → v5 和 encrypted v4 → v5 迁移保留明确验证。
- portable JSON、encrypted backup 与 Zotero Handoff 共用写入前预检和体量上限；取消预览不会写入。
- 加入浏览器端到端测试、CodeQL、Dependabot、当前 GitHub Actions、高/严重依赖漏洞发布门禁和隐私安全诊断导出。
- 保持 PWA、离线 shell、用户确认更新、standard/encrypted workspace、本地备份和双语界面。

## 隐私与安全边界

- 不增加账号、云数据库、默认同步、遥测或必需 AI 服务。
- 诊断导出不含工作台名称/ID、标题、笔记、主张、证据、TheoryMemo 正文、Zotero 元数据、口令或密钥。
- 所有 Zotero GUI 证据来自隔离的合成测试 profile；没有访问真实文库、账号、附件、笔记或同步状态。
- 中国省级田野地图本版本暂缓，没有发布任何地图边界或地图 API。

## 已知限制

- 没有账号、云同步、密码重置、恢复密钥或遥测。
- 中国省级田野地图、Claim–Evidence–Manuscript provenance、advanced quantitative reproducibility、advanced qualitative coding、global search、command palette 和 AI 功能不在本版本中。
- Zotero 插件 `0.1.0` 的发布证据覆盖隔离合成 profile 中的 Zotero 8.0.4 与本机已安装 Zotero 9.0.6；不代表所有未来 Zotero 版本。
- 已知外部研究者测试人数仍为 0；CI、维护者测试和合成 profile 不计为外部采用。

## English

Sociology PhD Desk v0.3.0 brings selected-reference Zotero handoff, an explicit import preview, and stricter local-data safeguards into the same account-free, cloud-optional research workstation. Existing standard and encrypted workspaces remain compatible, and research data stays in the local workspace chosen by the researcher.

### Zotero integration

1. Download the Zotero plugin and SHA-256 file from this Release.
2. Install the plugin from file in Zotero 8 or Zotero 9.
3. Select one or more regular bibliographic items.
4. Right-click Send to Sociology PhD Desk.
5. Choose the project, reading status, and priority in the Desk preview, then confirm the write.

Zotero remains the system of record for bibliography, PDFs, notes, annotations, and citations. The Desk accepts allowlisted bibliographic fields only from explicitly selected items and offers conservative DOI, ISBN, and title/year duplicate suggestions; it never merges automatically.

**The integration does not read or import PDFs, attachments, private notes, or annotations.** It also excludes full text, attachment paths, Zotero account data, and synchronization state, and it performs no background sync or write-back.

### Highlights

- Active primary navigation groups can be collapsed and reopened without changing research data.
- Portable workspace and standard database advance to v5, with explicit legacy and authenticated encrypted migration coverage.
- Portable JSON, encrypted backup, and Zotero Handoff share write-free preflight and bounded local parsing.
- Browser E2E, CodeQL, Dependabot, current GitHub Actions, high/critical dependency gating, and privacy-safe diagnostics are included.
- PWA, offline shell, user-approved updates, standard/encrypted workspaces, local backup, and bilingual operation remain supported.

### Privacy and security boundary

- No account, cloud database, default synchronization, telemetry, or required AI service was added.
- Diagnostics exclude workspace names/IDs, titles, notes, claims, evidence, TheoryMemo content, Zotero metadata, passphrases, and keys.
- Zotero GUI evidence used isolated synthetic profiles only; no real library, account, attachments, notes, or sync state was accessed.
- The province-level China fieldwork map is deferred; no map boundary or map API ships in this release.

### Known limitations

- There is no account, cloud sync, password reset, recovery key, or telemetry.
- The China map, Claim–Evidence–Manuscript provenance, advanced quantitative reproducibility, advanced qualitative coding, global search, command palette, and AI features are outside this release.
- Zotero plugin `0.1.0` evidence covers isolated synthetic profiles on Zotero 8.0.4 and the locally installed Zotero 9.0.6; it is not a claim about every future Zotero version.
- Known external researcher testers remain 0; CI, maintainer testing, and synthetic profiles are not external adoption.
