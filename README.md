# 社会学博士研究工作站

**把文献、田野、分析与写作安排在同一张研究桌上。**

面向社会学博士研究者的本地优先工作站。无需账号，中文优先并提供完整英文界面；浏览器即可使用，也可安装为 PWA。

## 从阅读到修回，让研究对象彼此衔接

| 工作 | 现在可以做什么 |
| --- | --- |
| **研究导航** | 从当前或明确选定的全部项目检索17类记录；查看原文、已有稳定ID关系与实际项目队列。查询仅在内存中，所有结果与关联可翻页。 |
| **文献与 PDF** | 手动登记文献、查看与编辑记录、附加本地 PDF；PDF 上传与 Zotero 元数据导入使用独立入口。保存后显示完整的当前范围列表，失败时保留输入。 |
| **项目空间** | 选择项目后，研究模块显示相关记录，新记录自动归属当前项目。切换项目只改变显示；写入和备份保留整个工作台。今日目标是工作台共同目标。 |
| **任务与日期** | 查看实际截止日期、剩余或逾期天数及未来七天任务；重新编辑期限与备注，保留完成状态。打开的页面会在本地午夜、聚焦或恢复可见时刷新日期。 |
| **本地田野标注** | 导入自己有权使用的 PNG/JPEG 地图或草图，以图内百分比关联同项目田野点，查看关联访问与访谈。支持点击、键盘及百分比输入；移除标注不删除原记录。 |
| **私密工作台与备份** | 隔离多个本地工作台，可选择加密存储、锁定与 `.sociologydesk` 加密备份。普通和加密备份均包含所有项目、PDF、图像与标注。 |

应用连接研究问题、文献、数据集或访谈、分析、证据、主张、论文与修回工作；它补充 Zotero、Word、Stata、R、Python 和 NVivo 等专业工具。Evidence↔Claim↔Manuscript 的完整显式追踪仍是独立的 [Issue #2](https://github.com/Yoesher/sociology-phd-desk/issues/2)，各模块编辑/删除能力尚未完全一致。

## 三步开始

1. **打开网站，建立工作台。** 无需注册。先体验合成演示，再建立自己的普通或加密工作台；普通浏览器访问始终支持完整工作流。
2. **选好项目，登记研究记录。** 从文献、任务或田野点开始。本地草图是可选入口；没有地图也可以继续记录田野访问与访谈。
3. **生成并验证备份。** 使用 `.sociologydesk` 备份恢复到新的隔离工作台，以备份方式迁移设备。PWA 安装和本地保存不会自动产生第二份副本。

首次成功加载并缓存后，应用静态资源可离线启动。出现更新提示时，“稍后”保留当前版本；保存编辑、生成并验证备份后选择“立即更新”，再到帮助中心核对应用版本与构建身份。不要清除站点数据或重置工作台来更新。网页关闭后没有系统通知或后台期限推送。

## 附件容量与数据迁移

| 内容 | 当前边界 |
| --- | --- |
| 本地 PDF | 每个 **10 MiB**，整个工作台合计 **20 MiB**；点击下载时才解码。 |
| PNG/JPEG 图像 | 每个 **2 MiB**，整个工作台合计 **4 MiB**；单边最多 **8,192 像素**，总面积最多 **1,600 万像素**。 |
| 完整普通 JSON | **32 MiB**，包含所有项目、记录与 base64 附件；普通文件导入也在读取前检查此上限。 |
| 加密备份 | 沿用 **64 MiB 密文**上限及独立附件限额；认证标签和封装另有边界，不能当作无限容量。 |

1 MiB = 1,048,576 字节。Base64 和可读 JSON 有额外开销，附件分别未达上限也可能使完整普通 JSON 超限。导出和新的超限增长会明确拒绝，保留输入与原数据，不截断附件、不只备份当前项目。

已有合法超限工作台仍可完整读取、迁移和进行不增加序列化大小的写入；在原加密容量与附件约束内可用完整加密备份保全。更大量 PDF 需要后续独立附件存储与分块认证备份，目前未实现，请保留自己的原文件。

当前 portable workspace、标准数据库与 authenticated encrypted payload 为 **v7**；container、vault database、registry database 仍为 **v1**。v6 → v7 保留旧记录，只增加空的本地地图集合，不推断图片或坐标。旧版 0.3.1 不能读取 v7 备份；跨版本前保留并验证原版本备份。导入先验证预览，替换必须明确确认；加密恢复先认证、验证，再创建新的隔离工作台，口令错误或密文损坏不会写入目标。

完整流程见[本地地图与存储指南](docs/local-field-maps-and-storage-2026-10-04.md)和[数据迁移说明](docs/data-portability.md)。

## 本地优先，也认真对待研究隐私

**不要存储可直接识别参与者身份的信息。** 使用别名和匿名 ID，不录入姓名、电话、证件号码、精确住址、签名或完整知情同意书。

- 研究数据默认保存于当前浏览器配置文件的 IndexedDB，无账号、默认云同步、分析统计、第三方跟踪器或必需 AI API。不同工作台使用独立数据库，但处于同一 Web 来源的信任边界内。
- 标准工作台与普通 JSON 是明文。仅明确标为加密工作台或 `.sociologydesk` 备份的内容使用应用层加密；界面锁定不等于加密。工作台名称、时间、模式等注册表信息与大致存储大小仍可见。
- 数据集、脚本和输出路径只是引用，不读取文件内容；自选 PDF 和图像保存实际字节。本工具不是源数据、访谈全文或不可替代资料的安全保管库。
- 本地图像只能是有权使用的县域或更粗研究示意、或匿名公共场所，不包含参与者住宅、精确位置或身份信息。原始字节及可能存在的 **EXIF/GPS 不会自动清除**；图内百分比与别名不保证匿名、授权或地图审查合规。
- 不提供全国底图、省市县浏览、行政区目录、在线瓦片、外部地图 API、GPS 获取或地图图像公开导出。全国地图四项门禁仍为 **BLOCKED**；本地素材工具不完成或绕过这些门禁，也不自动上传素材、标注或研究记录。

浏览器存储可能被清除，设备可能损坏；加密无法保护已解锁会话或失陷设备，忘记口令且失去备份可能无法恢复。删除 IndexedDB 不是安全擦除。请维护并实际测试独立备份，遵守机构的伦理、知情同意、保留期限与数据保护要求。没有读取用户真实数据库，不能声称原先找不到的文献已恢复。

## Zotero 保持书目管理职责

Zotero 仍是书目、PDF、笔记、批注和引用的权威系统。在 Zotero 8/9 中选择文献并发送到工作站后，核对导入预览、项目、阅读状态和优先级，再确认写入。

插件 **0.1.0 只交接允许的书目元数据**，不读取或导入 PDF、附件、私有笔记、批注、全文、账号或同步信息。本地 PDF 由工作站独立选择；没有自动 PDF 元数据提取。

**[下载插件 0.1.0](https://github.com/Yoesher/sociology-phd-desk/releases/download/v0.3.0/sociology-phd-desk-zotero-0.1.0.xpi)** · [SHA-256 校验文件](https://github.com/Yoesher/sociology-phd-desk/releases/download/v0.3.0/sociology-phd-desk-zotero-0.1.0.sha256) · [安装与使用](docs/zh-CN/zotero-integration.md)

插件继续使用既有 v0.3.0 正式资产，此应用更新不代表新增插件发行。

## 九个研究工作域，一条研究生命周期

| 工作域 | 用途 |
| --- | --- |
| 今日工作台 / 研究项目 | 共同目标、任务、研究问题、方法与项目进展。 |
| 文献队列 / 理论研究 | 阅读用途、PDF、概念、机制和理论 memo，与同项目问题、主张、文献关联。 |
| 田野与访谈 / 定量分析 | 别名田野点、访问、访谈与可选草图；数据集和 Stata/R/Python 分析运行。 |
| 证据台账 / 研究日志 | 来源定位、发现、局限、支持程度，以及研究判断与下一步。 |
| 论文与投稿 | 写作阶段、投稿、审稿意见、回复与修回行动，保留各实体和历史。 |

React、TypeScript、Vite 构建界面；Dexie 管理 IndexedDB，Zod 验证可迁移数据，Web Crypto 提供可选认证加密。界面语言与研究工作台分开保存，切换中英文不改写标题、笔记或其他用户文本。没有账号、云同步、通用 AI 助手或地图服务。

## 开发与贡献

已验证的开发环境为 **Node.js 24 / npm 11**。使用启用 IndexedDB 的现代浏览器；实际浏览器测试覆盖与版本验收以[项目状态](PROJECT_STATE.md)为准。

```bash
git clone https://github.com/Yoesher/sociology-phd-desk.git
cd sociology-phd-desk
npm ci
npm run dev
```

打开 Vite 显示的本地地址。不同浏览器配置文件或设备不会自动共享记录。完整发布检查使用以下原始命令；Playwright 需要相应 Chromium 浏览器运行环境。

```bash
npm ci
npm run audit:release
npm run lint
npm run typecheck
npm test
npm run test:zotero
npm run build
npm run test:e2e
```

只有当前修订上实际成功的检查才能报告通过。Zotero 构建可能生成哈希文件；核对生成变化，不要把本地重打包哈希当作既有正式下载资产的哈希。
