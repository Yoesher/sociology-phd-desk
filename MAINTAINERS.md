# Maintainers

## Current maintainer

- [Yoesher](https://github.com/Yoesher) — primary maintainer

The primary maintainer is responsible for issue triage, pull-request review, release decisions, migration and privacy review, security maintenance, and verifying release evidence. A maintainer role does not imply that external users, testers, or contributors exist.

## Contact routes

- Bugs and fully redacted reproduction cases: [Bug report](https://github.com/Yoesher/sociology-phd-desk/issues/new?template=bug_report.yml)
- Research-workflow feedback using synthetic or fully redacted examples: [Researcher testing feedback](https://github.com/Yoesher/sociology-phd-desk/issues/new?template=researcher_testing_feedback.yml)
- Security vulnerabilities: use the private route described in the repository [Security policy](https://github.com/Yoesher/sociology-phd-desk/security/policy); do not disclose vulnerabilities or research data in a public issue

No private maintainer email address is published by this repository. Do not send participant data, fieldnotes, transcripts, private Zotero content, credentials, passphrases, encryption keys, or unpublished research material through any project contact route.
